# Case-study artifact previews

These are locally optimized views of existing public portfolio artifacts. They
are not new product mockups and do not introduce new outcome claims.

- `frontline-discovery.webp`: cropped from
  `public/images/chatgpt-enterprise/frontline-ideation.png`, the sanitized
  discovery exhibit on `/work/chatgpt-enterprise`.
- `adoption-operating-model.webp`: cropped from
  `public/images/chatgpt-enterprise/enterprise-ai-operating-model.png`, a sanitized
  operating-model exhibit on the same case study.
- `champions.webp`: cropped from
  `public/images/chatgpt-enterprise/grassroots-champions-model.png`, a sanitized
  exhibit of the adoption network in the same case study.
- `sound-synthesist.webp`: cropped to the product visual in
  `public/images/sound-synthesist/product-visual.png`, used by
  `/work/ai-platform-mcp` to show the functional custom GPT prototype.
- `prototype-validation.webp`: cropped from
  `public/images/sound-synthesist/ux-validation.png`, the published prototype UX
  validation exhibit in that case study. The 87% result remains a user-testing
  finding, not a production-adoption metric.
- `omnichannel-concepts.webp`: optimized from
  `public/images/sound-synthesist/omnichannel-concepts.png`. These are conceptual
  ecommerce, in-store, and contact-center extensions; they are labeled as
  concepts, not production interfaces.
- `resume-generator.webp`: actual local browser capture
  of the existing public `/resume/generate` form. The WebP crops out the site
  header/footer and preserves the full form, including its generation action.
  No generation was submitted.
- `public-resume-output.webp`: first page rendered from the existing public
  `public/resumes/daniel-nash-ai-product-leader.pdf`. The public resume README
  identifies that PDF as a ResumeCustomizer output. This is an existing public
  download, not a newly generated or role-tailored output.
- `governed-career-workflow.webp`: optimized from
  `public/images/products/ai-career-operating-system/governed-ai-workflow-career-evidence.png`,
  the published system diagram on `/products/ai-career-operating-system`.

The preview preserves source illustrations as illustrations, sanitized exhibits
as sanitized exhibits, conceptual work as conceptual work, and actual captures as
captures. The original source assets and public pages remain unchanged.
