# Immunology Scout portfolio captures

These are screenshots of Daniel Nash's actual `MechanismsWorkspace` React Flow
interface, copied to an isolated temporary preview from:

`/Users/danielnash/Code/DanielNash/Immiatrics/immunologyscout/components/mechanisms/MechanismsWorkspace.tsx`

Captured November 13, 2026. The UI and graph renderer are original application
code. The underlying source application was not modified. No real research
thread, private scientific material, credentials, database, external retrieval,
or AI request was used. The temporary app had no API handlers; its automatic
validation request returned local 404.

All Aster study names, entities, relationships, evidence statuses, confidence
values, and source notes are invented demonstration fixtures. They are not
scientific claims. The screenshots explicitly call the study and notes fictional;
the portfolio labels them as a fictional example. The demo uses generic invented
labels including Candidate RX-17, Antigen A-12, Cell population C-8, and Signal
pathway P-4. There are no fabricated PMID, DOI, patent, or external source links.

- `aster-map-close.webp`: the actual connected graph with multiple evidence states.
- `aster-relationship-close.webp`: the same graph after keyboard selection of a
  fictional relationship, highlighting its connected nodes.
- `aster-source-detail.webp`: the actual evidence panel, cropped to the fictional
  study note and its source trail.

Captures were made through the browser at a desktop breakpoint, then cropped from
the full viewport image around the connected nodes (720 × 380) or source card
(350 × 350), excluding the large surrounding canvas and summary. The portfolio scrolls through those
screens and also provides three keyboard-accessible screen selectors. The preview
retains the public project's `Concept in progress` framing; these screenshots do
not establish a product launch, scientific validity, or expert approval.
